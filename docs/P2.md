# P2 — Context + Network Defense

P2 makes Blue Team a defensive product, not a model page.

> Red Team generates and stress-tests. Blue Team observes, detects, identifies, investigates, scores, and mitigates.

P2 specifically detects **contextual and coordinated fraud** that P0 can miss (quiet mule networks, shared device/IP, impossible travel).

## Models

- `BLUE-FRAUD-0.2.0` — binary detector on P0 features + geo / device / IP / beneficiary / graph
- `BLUE-ATTACK-CLS-0.2.0` — attack family classifier
- Deterministic risk engine 0–100

Labels never enter the feature vector. See `FEATURE_COLUMNS_V020` and `LEAKAGE_COLUMNS` in `backend/app/core/config.py`.

## Blue Team questions

1. Is this transaction suspicious?
2. What type of fraud is it?
3. Why?
4. Individual or coordinated?
5. How risky?
6. What should we do?
