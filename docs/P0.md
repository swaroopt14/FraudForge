# P0 — Baseline detector lab

P0 is the frozen row-level lab:

IEEE-CIS payments → five seeded attack families → Logistic Regression + LightGBM → risk policy + SHAP → an adversarial report.

## What P0 does

- Ingest IEEE-CIS into a payment schema
- Generate legitimate rows, then overlay five families: account takeover, velocity, amount anomaly, beneficiary anomaly, low-and-slow
- Train `BLUE-0.1.0` on 15 `FEATURE_COLUMNS` with **no label leakage**
- Score with ALLOW / STEP_UP / REVIEW / BLOCK
- Write a computed adversarial report (not hardcoded metrics)

## Frozen contract

`FEATURE_COLUMNS` stays 15 columns. Do not put `attack_family`, `fraud_label`, `simulation_id`, or Red Team metadata into X.

## UI of record

The product UI is the Next.js lab with a **left sidebar**, not Streamlit.
